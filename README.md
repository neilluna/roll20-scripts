## Installation

Install the following mods in any order:

- Paraselene-Common.js
- Paraselene-Installer.js
- Paraselene-Tools.js
- Paraselene-DnD5e.js
  - This script is only required if you are playing D&D 5th edition.

Once the scripts are installed, run the following command

`!Paraselene-Installer-Install --speakAs Install`
